* Responsibility and API
This child owns appearance. Data parsing, physical interpretation, analysis and
natural-language interpretation remain with separate owners. Standard Matplotlib
owns plotting. This package needs no agent, notebook or plotting companion.

- =PRESETS= is =(personal,)=. =COLOR_MODES= is =(color, monochrome)=.
- =plot_defaults(name="personal")= returns a fresh dictionary with figsize, dpi,
  linewidth, markersize, labelsize, tick_labelsize and bbox_inches.
- =style_context(name="personal", overrides=None, *, color_mode="color")=
  yields name, canonical_name, color_mode, version, defaults, font, text_engine
  and notes. It restores rcParams after normal/error exit and nesting.
- =dash_pattern(pattern, preset="personal")= retains source-derived custom dash
  tuples independently of mode; =batlow_colors(positions)= returns installed
  cmcrameri RGBA values without global colormap registration.
- =helpers.HandlerXoffset= and =helpers.draw_matrix_legend= retain the two legend
  mechanisms. Three layout/legend examples remain explicitly synthetic.

* Common baseline and modes
The existing personal baseline is preserved: 6×6 inches, line 2.5 pt, marker
8 pt, label/tick text 15 pt; inward major ticks 6/1.2 pt, minor 3/.8 pt, spines
1.5 pt. DejaVu Sans and Mathtext are portable choices. 300 dpi is an explicit
export fallback. The researcher clarified a shared style with black-and-white
or color presentation; year/author labels no longer select different geometry.

Color uses authentic batlow .2/.7. Monochrome cycles black lines with solid,
dashed, dash-dot and dotted styles to distinguish curves without color.
Explicit artist arguments and validated appearance overrides take precedence.
Markers/fills are caller choices; no forced scatter fill is inferred. Line2D
and PathCollection keep distinct normal Matplotlib semantics.

Friendly overrides are the seven defaults; direct overrides use the finite
numeric/color rc allowlists, tick direction and legend.frameon. Invalid values,
unknown modes and nonappearance keys fail before state mutation. Backend, TeX
execution, physical quantities, scales, limits or transforms are not overrides.

* Data and configuration
=wb_plot_styles/presets.json= is a UTF-8 JSON resource. The runtime reads
=personal= and expects four field groups:

| Field/group | Type and meaning |
|-------------+------------------|
| defaults.figsize | Two positive numbers in inches, width then height. |
| defaults.dpi | Positive raster dots per inch; 300 is the adapter's explicit fallback. |
| defaults.linewidth, markersize, labelsize, tick_labelsize | Positive sizes in points. |
| defaults.bbox_inches | Export bounding-box policy; this preset stores tight. |
| rc | Matplotlib keys for inward x/y ticks and point sizes/widths; axes.linewidth sets spine thickness in points. |
| font | Requested font name; fallback is DejaVu Sans. |
| notes | Ordered strings recording how defaults were selected. |
| dash_patterns | Exact name to nonempty alternating stroke/gap point lengths; list order is meaningful. The API supplies a zero offset. |

For example, =dashdotdotted= stores =[3,5,1,5,1,5]= and yields
=(0,(3,5,1,5,1,5))=. Relative to the Matplotlib v3.10.7 gallery, named
=dotted= is =[1,1]= here, with the gallery's other eleven shared named
rows retained. =-..=, =-...= and =:= are local lookup aliases. See
[[file:../REFERENCES.md][dash and palette provenance]].

=pyproject.toml= defines build backend, Python and dependency requirements,
the installed package, the JSON resource, and license-notice inclusion.
=provenance.json= records the style identity and source, dependency pins,
license, attribution, source hashes and versioned decisions. It is descriptive
and does not configure Matplotlib. The example's =rendering.json= contains
=synthetic=, a =vertical= context and =presets= in color-mode order. Each
context exposes the mode, defaults, selected and requested font, text engine,
version and notes. Generated PNG/PDF files represent the synthetic display.
