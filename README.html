Scientific Composability for Multiscale Simulation

These independent presets help prepare computations, read outputs and present results. For example, a particle simulation can produce a table of validated transport properties with units and an applicable concentration range. A continuum solver can consume an interpolated value from that table. A plotting preset can then present both datasets in a common style.

  • Level 1 Modernization preserves a runnable baseline and maps interfaces and architecture.
  • Level 2 Modernization preserves the numerical architecture and verifies changed operations and retained outputs.
  • Level 3 Modernization aims at scientific composability for multiscale simulation and checks that independent components can exchange a defined physical quantity.

An internal BD–MC and mBLA project has exercised live transport-property evaluation. The practical workflow interpolates a table of precomputed properties to reduce evaluation time. Live evaluation is being extended to conditions that need a fresh property calculation. A future ML surrogate could use the same interface after validation over its applicable range.

The Scientific Modernization plugin in the companion wb-plugins collection owns the workflow. A shared soft-matter validation layer for pressure, diffusivity and stress is planned. Use the template’s own evidence when deciding whether a particular result is ready for use.

Try plotting

Python 3.10+ and each child’s declared dependencies are required. From this collection, in your chosen environment:

python3 -m pip install ./plot-styles ./scientific-io
python3 -B examples/plot_csv.py --output /tmp/my-new-wb-plot

The example creates its own explicitly synthetic CSV and produces PNG/PDF plus rendering metadata in a new directory. It does not run a scientific solver. Choose another new output name if that directory already exists. To view layout and legend examples, run plot-styles/examples/render_examples.py --output with a new path after installing the plotting packages.

import matplotlib.pyplot as plt
from wb_plot_styles import style_context

with style_context(color_mode="monochrome") as rendering:
    fig, ax = plt.subplots(figsize=rendering["defaults"]["figsize"])
    ax.plot([0, 1], [0, 1], marker="o")
    ax.set(xlabel="x (synthetic)", ylabel="y (synthetic)")
    fig.savefig("my-figure.pdf", bbox_inches="tight")

The common personal style has two presentation modes: color (default, authentic batlow cycle) and monochrome (black with distinct line styles). Geometry, text and line widths are shared. Source author/year information stays in provenance. Use explicit appearance overrides for project-specific sizes.

Copy, verify and adapt

python3 tools/verify_manifest.py
python3 tools/export_template.py --template plot-styles --destination /tmp/my-new-plot-styles

An independent copy retains its license, notices, tests and provenance. Install the selected child’s declared dependencies separately. Choose a new destination. The copy tool accepts regular source files.

Validation and reproduction describes the tested behavior and replay commands. Run the chosen child’s documented tests. A smoke test, regression, physical consistency check and scientific acceptance establish different things. Fonts/TeX may differ; no pixel identity with published figures is claimed. Styles do not infer units, transform data, select a physical model or validate a solver.

Org files are plain text. Markdown #/## correspond to Org */**, and [[file:path][label]] is a local link. The collection provides its README in English, German and Korean. Technical guides use English.

Attribution and licensing

Preserve Gunwoo Park’s original authorship, retained third-party attribution and scientific and software citations. Scientific and software checks have the scope described in the validation guide. Human direction, performed checks and human review are distinct. The root MIT license covers newly authored common material, subject to child-specific exceptions. Apache-derived HI material keeps its license/NOTICE, and separately installed dependencies keep their own terms. The source packages carry no dependency binaries or separate font packages. Rendered publications can embed font subsets. The plotting source carries the collection MIT grant and the applicable upstream notices.

Plotting authorship and color references

Gunwoo Park authored the original paper plotting scripts and style. The examples contain unrelated synthetic data, not original paper filenames, schemas or results. See style/paper and batlow references and the actual cmcrameri1.10 MIT notice.
