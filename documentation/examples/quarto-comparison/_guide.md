## Using wb-templates {#using-wb-templates}

wb-templates is the reusable scientific-computation collection of Agentic
Workbench (wb). Its templates include assumptions, small inputs and bounded
verification evidence. Copy the template's source folder with its license
and guide, then select an example close to your own calculation.

- **Scientific Modernization** provides portable baselines, operation-level
  checks and worked scientific-interface comparisons. Read each solver's
  declared validation domain.
- **Plot styles and CSV I/O** provide reusable presentation settings and
  explicit numeric column selection.
- **Documentation and review** turn authored evidence into detailed and
  presentation views. Multiple ordered Markdown chapters feed this continuous
  page. A Reveal.js deck links back to exact sections and the same data.

### Replace the example with your own work

Copy this kit. Add or replace Markdown files with a leading `_` and list them in
the intended order in `report.qmd`. Use unique section IDs. Keep the equations,
validation criteria and source comparisons in the report. In `slides.qmd`,
keep selected figures and checks and link to the report sections. Update the
edition and publication identity together when reusing the layout.
