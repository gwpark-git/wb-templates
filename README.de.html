Kombinierbare Bausteine für Mehrskalensimulationen

Diese unabhängigen Vorlagen helfen, Berechnungen vorzubereiten, Ausgaben einzulesen und Ergebnisse darzustellen. Eine Partikelsimulation kann etwa eine Tabelle geprüfter Transporteigenschaften einschließlich Einheiten und Gültigkeitsbereich der Konzentration liefern. Ein Kontinuumslöser kann einen interpolierten Wert aus der Tabelle übernehmen. Eine Grafikvorlage kann anschließend beide Datensätze im selben Stil darstellen.

  • Level 1 Modernization erhält eine lauffähige Referenz und dokumentiert ihre Schnittstellen und Architektur.
  • Level 2 Modernization erhält die numerische Architektur und prüft geänderte Verarbeitungsschritte und beibehaltene Ausgaben.
  • Level 3 Modernization soll die Kombination wissenschaftlicher Bausteine in Mehrskalensimulationen ermöglichen und prüft, ob unabhängige Komponenten eine definierte physikalische Größe austauschen können.

In einem internen Projekt mit BD–MC und mBLA wurden Transporteigenschaften bereits zur Laufzeit berechnet. Der praktische Ablauf interpoliert eine Tabelle vorberechneter Eigenschaften, um die Auswertung zu beschleunigen. Die Berechnung zur Laufzeit wird auf Bedingungen ausgeweitet, die eine neue Berechnung der Eigenschaft erfordern. Ein künftiges Ersatzmodell auf Basis maschinellen Lernens könnte nach Validierung in seinem Gültigkeitsbereich dieselbe Schnittstelle verwenden.

Das Plugin Scientific Modernization aus der ergänzenden Sammlung wb-plugins beschreibt den Ablauf. Eine gemeinsame Validierungsschicht für Druck, Diffusivität und Spannung in weicher Materie ist geplant. Ob ein bestimmtes Ergebnis verwendbar ist, ergibt sich aus den Prüfbelegen der jeweiligen Vorlage.

Mit einer Aufgabe beginnen

  • Ein wissenschaftliches Ergebnis prüfen. Öffnen Sie den mBLA Profile Explorer und vergleichen Sie Archiv und Nachrechnung in beiden Schnitten. Site hollow-fibre reference zeigt gespeicherte Konzentrations- und Strömungsprofile durch einen gewählten Punkt.
  • Einen älteren Löser wieder in Betrieb nehmen. Folgen Sie der BD–MC-Anleitung zu Build und Verifikation, um eine erhaltene Rechnung vor Änderungen auszuführen.
  • Eine Partikelsimulation mit einer Zustandsgleichung vergleichen. Das BD–MC-Beispiel zur Carnahan–Starling-Zustandsgleichung enthält die gespeicherten Ergebnisse von BD mit weicher Abstoßung und Hartkugel-MC samt Abbildungen und Angaben zur Stichprobe.
  • Einen Vergleich darstellen. Erzeugen Sie mit dem CSV-Grafikbeispiel PNG- und PDF-Dateien. Das Quarto-Beispiel zeigt, wie Sie die Methoden und Prüfbelege dokumentieren können.

Die Funktionsreferenz verweist für jeden Bereich auf Implementierung, Konfiguration, Eingaben und Prüfungen.

Die Vorlage für die wb-python-Schnittstelle unterstützt den skriptgesteuerten Umgang mit Session Profiles und Agent Profiles in künftigen wb-applications-Erweiterungen. Eine eigenständige Veröffentlichung der Laufzeitkomponente ist vorgesehen. Diese Sammlung enthält das Handbuch und das Beispiel. Für die Ausführung sind eine konfigurierte Sandbox und die separat bereitgestellte Laufzeitkomponente erforderlich. Die Jupyter-Integration bleibt ein separates Paket in wb-applications. Der Host-Client wb-client ist ein eigenständiges Projekt.

Grafikbeispiel ausprobieren

Sie benötigen Python 3.10 oder neuer und die angegebenen Abhängigkeiten des jeweiligen Teilpakets. Führen Sie aus dem Verzeichnis dieser Sammlung in Ihrer gewählten Python-Umgebung aus.

python3 -m pip install ./plot-styles ./scientific-io
python3 -B examples/plot_csv.py --output /tmp/my-new-wb-plot

Das Beispiel erzeugt eine eigene synthetische CSV-Datei und schreibt PNG, PDF und Metadaten zur Darstellung in ein neues Verzeichnis. Es startet keinen wissenschaftlichen Löser. Wählen Sie einen neuen Ausgabepfad, falls das Verzeichnis bereits existiert. Nach Installation der Grafikpakete können Sie mit plot-styles/examples/render_examples.py --output und einem neuen Ausgabepfad auch Layouts und Legenden ausprobieren.

import matplotlib.pyplot as plt
from wb_plot_styles import style_context

with style_context(color_mode="monochrome") as rendering:
    fig, ax = plt.subplots(figsize=rendering["defaults"]["figsize"])
    ax.plot([0, 1], [0, 1], marker="o")
    ax.set(xlabel="x (synthetic)", ylabel="y (synthetic)")
    fig.savefig("my-figure.pdf", bbox_inches="tight")

Der gemeinsame Stil personal bietet die Darstellungsmodi color (Standard mit originaler batlow-Farbreihenfolge) und monochrome (Schwarz mit unterscheidbaren Linienstilen). Geometrie, Textgrößen und Linienbreiten sind identisch. Die Quellenangaben enthalten Autor und Jahr. Abweichende Größen lassen sich für ein Projekt gezielt einstellen.
