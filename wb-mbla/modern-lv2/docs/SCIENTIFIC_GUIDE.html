mBLA C++ — scientific contract, configuration and output

Scope and unchanged model

The source is the researcher's 2026 JCP C++ mBLA edition. It models steady cross-flow ultrafiltration in a cylindrical hollow fibre, with an axial pressure solve, transverse matched concentration profiles, concentration/shear-dependent transport closures and a thresholded cake hydraulic-resistance extension. This template changes engineering interfaces and numerical failure reporting; it does not adopt a new physical closure. The public Python model lacks the cake extension. Agreement with Python is meaningful only for matched non-cake conditions, closure editions and numerical accuracy.

The maintained source manifest identifies the 21 copied .cpp/.h files by portable source ID and SHA-256. Original datasets, backups, object files, plotting scripts and manuscript material are not part of this template.

Fixed-point method and applicability

The inherited history-safety predicate, its ordering before relaxation/clamping, resistance persistence and stopping semantics are explained in the fixed-point method owner. The researcher identifies physically non-monotonic wall-concentration regions as outside this method's present applicability. The code does not automatically validate that physical regime; modernization preserves the safeguard.

MATRIX::data remains a non-owning public alias for compatibility with GSL. Do not reassign it, change public dimensions or hold a view across initial(), copyobj() or destruction. Copies own independent vector storage; indexing rejects invalid row/column/flat indices. GSL LU overwrites its matrix argument. Unused historical matrix helper APIs are retained, but the tests cover the solver's active subset, not every old printer/diagonalization helper.

Units and scaling

Inputs use metres, seconds, kelvin, pascal and volume fractions. Rchannel is channel radius, Lchannel is axial length, aparticle is excluded-volume radius and gamma=aH/a is hydrodynamic/excluded radius ratio. eta0 is Pa s and Lp is m/(Pa s). Pressure-inlet DLP=Pin-Pout; refPout is absolute outlet pressure.

Inherited scales are u0=R2 DLP/(4 eta0 L), vw0=Lp DTPHP, k=4 sqrt(L2 Lp eta0/R3), D0=kT/(6 pi eta0 aH), Piast=kT/Va and Va=4 pi a3/3. getPper preserves Pper=Pout+DLP/2-refDTP; refDTP is the linear Hagen-Poiseuille reference pressure parameter, not measured suspension mean TMP. The pure-solvent mean pressure applies 2 tanh(k/2)/k separately. Velocity-inlet uinlet sets the corresponding Hagen-Poiseuille DLP scale; actual Pin can differ after solving the Neumann inlet condition.

The GSL physical constant is deliberately unchanged. GSL 2.8 supplies kB=1.3806504e-23 J/K, rather than the current exact SI value. A library/constant update changes numerical identity and needs a labelled comparison.

Configuration grammar and supported controls

Each nonempty line is key=value; whitespace and # comments are allowed. Niter consumes the complete finite integral numeric value checked by the parser: 2400, 2.4e3 and 0x960 all mean 2400; nonintegral values fail. Duplicate/unknown keys, partially parsed numbers, nonfinite values, missing required fields and unsupported law names fail. Paths are literal filesystem paths relative to the process working directory, not the input file directory; there is no shell expansion. Serial positional inputs run in argument order; a failed case stops the remaining batch.

Required fields Meaning
Niter, weight Maximum fixed-point iterations; under-relaxation in (0,1]
Nz, Nr Axial and logarithmic transverse nodes, each >=3
Rchannel, Lchannel, Lp, eta0, T Positive geometry, permeability, solvent viscosity, temperature
refPout, refDTP Outlet pressure and positive reference TMP parameter
DLP or uinlet Positive inlet scale selected by inletBC
phibulk, phiwinit, phifreeze Feed, initial wall concentration and freezing threshold; 0<phibulk<phifreeze<1
aparticle, gamma Positive excluded radius and 0<gamma<=1
TOLphiw, TOLdeltaf Positive inherited fixed-point/search stopping settings
fcnDcdivD0, fcnetadiveta0, fcnPi Named closure or property-table filename
fout Main output destination; existing file is overwritten

Optional inletBC defaults to pressure; velocity is the other supported value. CONT, DETAILEDREPORT and ACCOUNTCAKETHICKNESS default to FALSE and accept only TRUE/FALSE. CONT=TRUE requires FNCONT: a finite rectangular table with exactly Nz rows and >=2 columns; column 2 initializes the wall concentration. The caller must ensure matching axial coordinates/physical conditions. ACCOUNTCAKETHICKNESS=TRUE requires positive membranethickness (metres). Without this flag, resistance is still calculated; geometric cake thickness stays zero. Numerical limits are Nz<=400, Nr<=4000 and Niter<=100000. These are finite default bounds, not a performance guarantee; select smaller limits and a time/data budget in a destination.

TOLphiw is applied to RMS differences of phiwall/phibulk, including the fixed inlet (whose increment is zero), even though the inherited log labels it like a relative norm. TOLdeltaf enters resistance increment/search and relative outlet-resistance stopping. The inherited stopping flag can latch before the mandatory minimum iteration count. Exit 0/MBLASTATUS=converged therefore names the inherited stopping event only. Exit 3/iterationlimit means exhausted iterations; output is retained for diagnosis. Invalid input/output (including a failed write, flush or close), nonfinite numerics or a stalled cake search fail with exit 2. Do not equate any exit-0 result with conservation or grid acceptance.

Constitutive choices and tables

Diffusion supports SPHS/HS (both mapped to the inherited SPHS diffusion), SID and CT (unity). Viscosity supports SPHS, HS, TEST, TESTEQ and CT. TEST variants are inherited shear-stress-dependent research options, not separately validated production models. Osmotic pressure supports CS and NO, or a table. The code preserves the source's high-frequency-viscosity expression; it does not replace its multiplication by a published denominator or unify the HS/SPHS variants.

A property table has exactly two finite numeric columns, at least three rows, strictly increasing volume fraction, and coverage of [0,phifreeze]. Blank lines and # comments are accepted. Diffusion/viscosity ordinates must be positive; they are dimensionless D/D0 and eta/eta0. Osmotic-pressure ordinates are in Pa, then normalized by Piast. The inherited natural cubic spline caps concentration above phifreeze; values below its domain fail. A valid table need not be a physically acceptable constitutive law; cubic interpolation can overshoot.

Runtime equilibrium transport

An application can link mbla_case_driver and call mbla::run_cases with a caller-owned mbla::EquilibriumTransport. Both transport selectors must be LIVE. The driver supplies the case's freeze fraction and reference Péclet number for provider admission. During the serial solve the provider receives the local volume fraction and returns positive finite collective D_c/D0 and relative eta/eta_s. Here the solvent viscosity eta_s is the same scale as the legacy input eta0. The provider owns sampling, interpolation if any, and the supported concentration range. It does not receive a local shear rate or stress because the interface is for local equilibrium closures. Osmotic pressure keeps its independently selected law. An ordinary CLI invocation with LIVE, a partial LIVE selection, or an invalid provider response fails with the existing execution-error exit status. Runtime interface

phicake and porosity are accepted legacy metadata with an explicit warning: the inherited implementation ignores these inputs and fixes phicake=0.64. Changing this behavior requires a separately reviewed physical/model change.

Ten-column inherited output

The main file is whitespace-delimited, no header, one axial sample per row, with six digits after the decimal point in scientific notation. Column numbers below are one-based. Do not silently reinterpret column 8 as cake thickness.

Column Stored quantity Unit / meaning
1 z m
2 phiwall volume fraction
3 P Pa
4 vwall m/s, positive permeation direction
5 u0 times dimensionless axial pressure-gradient factor m/s; not cross-sectional mean velocity
6 osmotic pressure Pa
7 inherited integrated particle-volume flux m3/s
8 (Rcake/Rmem) times Rchannel m as a mixed-normalization storage convention
9 P-Pper Pa
10 geometric cake thickness/Rchannel dimensionless; zero when thickness accounting is disabled

Recover Rcake/Rmem by dividing column 8 by the configured radius. Hydraulic permeability is Lp/(1+Rcake/Rmem); thus a useful independently reconstructed printed-value check is vwall=Lp*(column9-column6)/(1+column8/R).

With DETAILEDREPORT=TRUE, inherited .Rout has six columns: yt/Rchannel, phi, dimensionless shear rate, dimensionless shear stress, D/D0 and eta/eta0. yt already means y/R; the extra division makes its first column y/R2 (1/m). Multiply by Rchannel to recover y/R. This known source mistake is retained. .Fval has z/L, F1, F2 and modified F2. These sidecars describe the iteration state before final analysis and can lag its final recomputation; they are not a complete synchronized 2D field export. Inspect that contract before adapting.
