* Scientific attribution
The scientific source and test project are associated with Park et al.,
Journal of Chemical Physics 164 (2026), article 244119. The inherited Python
headers separately cite Park and Nägele, DOI 10.1063/5.0020986, and describe
later geometry work. These are source associations, not a reconstructed full
bibliographic verification or permission to redistribute unpublished code.
The optional public Python checkout identity belongs in each executed result;
no historical match is inferred from its present version.

* New-file license scope
LICENSE is authoritative for this child's exceptions. LICENSE.NEW reproduces
the collection MIT notice only for the explicitly named new original additions.
Derived research source and generated research fixtures are excluded from that
grant. No original dataset is included. An eventual public package needs an
explicit researcher/rightsholder decision and review of GSL-linked distribution.
