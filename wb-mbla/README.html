Evidence from the JCP 2026 reference

The regression data guide explains the stored grids, quantities and case coverage. Open the profile explorer to compare the full axial and outlet radial sections side by side. The site reference tab shows axial and radial concentration and flow through a selected point in the independent hollow-fibre preview.

The reference is the C++ solver used in Park, Dhont and Nägele, J. Chem. Phys. 164, 244119 (2026). Level 1 modernizes the build and interfaces. Level 2 preserves the numerical architecture and ports the inner cake-resistance search from C++ to Python, with optional Numba acceleration. The outer solver and CLI are C++. Eight selected CASE1/CASE2 TMP runs at 200 × 400 reproduce Level 1 output byte-for-byte and match archived mean TMP and permeate velocity at stored precision. The accepted profiles span the full axial domain, with CASE2 run at the reference setting b = 1. Mesh convergence and the high-TMP inlet regime have their own applicability limits. The Python/Numba replay agrees with C++ on 42 saved searches and 9,712 trials. These are bounded modernization checks for the recorded conditions and routines.

Build the root C++ baseline

Run these commands from the mBLA package root to build its baseline CLI. For a modernization-level build, use the Level 1 guide, Level 2 guide, or Level 3 guide. The Level 3 provider example builds against the sibling Level 2 source.

A C++17 template for Gunwoo Park’s cross-flow ultrafiltration solver, preserving its hollow-fibre concentration-polarization and cake-resistance calculations. It provides a CMake library/CLI, owned matrix storage, validated configuration and tables, and small immutable reference cases. This is internal research preparation; redistribution of the inherited unpublished source needs review. See license scope, notices and third-party evidence.

Install or otherwise provide a C++17 compiler, CMake 3.16+, GSL 2+ and Python 3 for the standard-library test runner. No network, plugin, original dataset or Python scientific stack is needed for the C++ build and standard tests.

cmake -S . -B /tmp/mbla-build -DCMAKE_BUILD_TYPE=Release
cmake --build /tmp/mbla-build -j2
ctest --test-dir /tmp/mbla-build --output-on-failure
mkdir /tmp/mbla-run
cp examples/cake-mild.inp /tmp/mbla-run/case.inp
cd /tmp/mbla-run
/tmp/mbla-build/mbla case.inp

fout=result.dat is resolved against the run directory and overwritten. A completed run prints MBLA_STATUS=converged; this names the inherited stopping criterion. Inspect conservation before interpreting its predictions. Run tools/inspect_output.py from the copied template with the resulting table:

python3 tools/inspect_output.py /tmp/mbla-run/result.dat \
  --radius 0.0005 --permeability 6.7e-10 --csv /tmp/mbla-run/result.csv

The examples distinguish a non-cake case, a mild cake case, and a demanding cake regression. The latter exposes substantial particle-flux error; the mild case also lacks a successful refined-grid confirmation. These are useful engineering and numerical diagnostics, not grid-converged cake validation. The inherited output has mixed normalization in its cake column; read the scientific/I/O guide before using it.
